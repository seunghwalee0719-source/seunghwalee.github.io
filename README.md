# SEE Lab Website v4

A GitHub Pages-ready multi-page site for the Sustainable Electrochemical Engineering Lab (SEE Lab), Sookmyung Women's University.

## Upload to GitHub
Upload the *contents* of this folder to the repository root:

- index.html
- research.html
- people.html
- publications.html
- news.html
- lab-life.html
- contact.html
- styles.css
- app.js
- assets/

Then enable GitHub Pages from `Settings → Pages → Deploy from a branch → main → /(root)`.

## What changed in v4
